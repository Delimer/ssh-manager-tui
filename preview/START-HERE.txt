sshm — SFTP Browser preview r5 для Windows 10 x64

Включены пакетная передача, внешний редактор и управление файлами/папками.
Это тестовая сборка. Она скомпилирована под Windows x64 из Linux;
запуск на настоящей Windows ещё не проверен.

1. Распакуйте весь ZIP в отдельную папку, например C:\Tools\sshm-preview.
   Устанавливать Rust, MinGW или Visual C++ Runtime для этой сборки не требуется.
2. Откройте PowerShell в этой папке:

   ssh -V
   .\sshm.exe

   Если ssh не найден, установите компонент Windows «Клиент OpenSSH».
   Программа читает серверы из %USERPROFILE%\.ssh\config.
3. Для редактирования через установленный Notepad++ задайте в этом же PowerShell:

   $env:VISUAL = '"C:\Program Files\Notepad++\notepad++.exe" -multiInst -nosession'
   .\sshm.exe

   Поправьте путь, если редактор установлен в другом месте.
   VISUAL имеет приоритет над EDITOR. Редактор должен оставаться запущенным
   до сохранения и закрытия файла. Для VS Code используйте Code.exe --wait.

Проверка на тестовом сервере и тестовых файлах:
- На сервере в списке нажмите b — откроется SFTP browser.
- Tab переключает панели. Space отмечает файл; Ctrl+A отмечает все файлы.
- Отметьте три файла, нажмите Enter. Проверьте результат на второй панели.
- Esc снимает выделение; без выделения закрывает браузер.
- На удалённом файле нажмите F4 или e, измените его в редакторе,
  сохраните и закройте редактор. Проверьте новые байты на сервере.
- Повторите открытие без изменений: повторной загрузки быть не должно.
- Измените удалённый файл другим способом, пока редактор открыт:
  при сохранении должно появиться подтверждение конфликта.
- При ошибке сохранения локальная копия остаётся; её путь показан в браузере.
- Если используете ssh-agent и IdentityFile *.pub + IdentitiesOnly yes,
  отдельно проверьте передачу, редактор и операции с папками.

Действия в стиле Midnight Commander (в активной панели):
F4 — редактировать удалённый файл; F5 — копировать файл, отмеченные файлы или папку со всем содержимым;
F6 — переименовать; F7 — создать папку; F8 — удалить с подтверждением.
Shift+N создаёт пустой файл. Прежние C, R, n, Delete и d тоже работают.
Копирование папки отказывается заменять существующую папку назначения.
Enter по-прежнему открывает папку.

Подробные чек-листы — в приложенных sftp-*.md.

Ограничения: редактор проверяет конфликт до сохранения, но не выполняет
атомарный compare-and-swap. POSIX mode сохраняется; ownership/ACL/xattrs
не гарантированы. Сборка не подписана. Вывод --version пока остаётся 1.2.0,
поэтому для идентификации этой preview используйте BUILD.txt и SHA256SUMS.txt.
